# Remoter

Telegram-бот, который превращает твой телефон в пульт от этого ПК: ты пишешь задачу в Telegram,
а локальный [OpenCode](https://opencode.ai) выполняет её в терминале. Бот показывает прогресс,
присылает код и диффы, делает скриншоты и спрашивает подтверждение перед опасными действиями.

```
Telegram  ──►  Remoter (WinForms, трей)  ──►  OpenCode service (127.0.0.1)  ──►  файлы / терминал
```

Remoter сам ничего не выполняет — он создаёт сессию OpenCode, отправляет промпт, слушает события
и превращает запросы разрешений в inline-кнопки.

---

## Что нужно

- Windows 10/11, .NET 10 (SDK или Desktop Runtime).
- Установленный и настроенный OpenCode (команда `opencode` доступна в PATH).
- Аккаунт Telegram и токен бота от [@BotFather](https://t.me/BotFather).
- Модель с доступным лимитом/балансом в OpenCode.

## Быстрый старт

### 1. Получи токен бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot`.
3. Придумай имя (например, `My Remoter`) и username, заканчивающийся на `bot`
   (например, `my_remoter_bot`).
4. BotFather пришлёт строку вида `123456789:AA...` — это токен.

> Никому не показывай токен и не коммить его. Он хранится только в `.env`.

### 2. Запусти Remoter и заполни `.env`

Запусти `Remoter.exe` (или `dotnet run --project src\Remoter.App`). При первом запуске рядом
с exe появится файл `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=
ALLOWED_USER_IDS=
```

Вставь токен:

```dotenv
TELEGRAM_BOT_TOKEN=123456789:AA...
```

### 3. Узнай свой Telegram ID

Перезапусти Remoter и напиши боту `/start`. Пока `ALLOWED_USER_IDS` пуст, бот работает
в режиме настройки: он отвечает только твоим ID и ничего не выполняет.

Скопируй ID в `.env`:

```dotenv
ALLOWED_USER_IDS=123456789
```

Можно несколько ID через запятую. Перезапусти Remoter — бот готов.

### 4. Проверь цепочку без Telegram

```powershell
Remoter.exe --selftest
```

Проверяются: поиск/запуск сервиса OpenCode, создание сессии, отправка промпта, поток событий
и финальный ответ. Результат пишется в консоль и в лог. Код возврата `0` — успех.

## Команды

| Команда | Что делает |
| --- | --- |
| *(любой текст)* | Задача для агента в текущей сессии |
| `/start` | Статус, папка, модель, агент |
| `/help` | Список команд |
| `/id` | Твой user/chat ID |
| `/new [путь]` | Новая сессия (по умолчанию — текущая папка) |
| `/sessions` | Последние сессии OpenCode |
| `/use N` | Переключиться на сессию из списка |
| `/status` | Что выполняется сейчас, очередь |
| `/cancel` | Прервать задачу и очистить очередь |
| `/agent [build\|plan]` | Режим агента: выполнять или только планировать |
| `/model [имя]` | Выбрать модель (без аргумента — кнопки) |
| `/screen` | Скриншот экрана (если сессия не заблокирована) |
| `/file путь` | Прислать файл или картинку |
| `/ls [путь]` | Содержимое папки |
| `/diff` | Изменения текущей сессии |
| `/restart` | Перезапустить сервис OpenCode |
| `/shutdown` | Выключить Remoter |

Пока задача выполняется, новые сообщения ставятся в очередь. Длинный ответ приходит файлом,
код — блоками `<pre>`, прогресс обновляется в одном сообщении.

## Свои модели и агенты

Remoter не привязан к конкретной модели — он работает с тем, что настроено в OpenCode.
Модель и агент задаются в `appsettings.json`/`.env` и переключаются на ходу из Telegram:

```dotenv
MODEL_PROVIDER=opencode
MODEL_ID=deepseek-v4.1-flash-free
AGENT=build
```

- `/model` — список моделей из OpenCode, выбор кнопками;
- `/agent build` — агент с правками и командами, `/agent plan` — только планирование;
- любые свои агенты и провайдеры, добавленные в OpenCode, тоже появятся в боте.

Если у модели закончился лимит, бот покажет ошибку провайдера — просто выбери другую модель
через `/model`.

## Подтверждения

Без спроса разрешено только чтение: `read`, `glob`, `grep`, доступ к папкам вне проекта.
Правки файлов, команды в терминале, сеть, веб-поиск и субагенты приходят с кнопками:

- **✅ Разрешить** — один раз;
- **🔁 Всегда** — до конца сессии;
- **❌ Отклонить** — действие не выполняется.

Чтение `.env` тоже требует подтверждения (кроме `.env.example`). Если не нажать кнопку
за `APPROVAL_TIMEOUT_SECONDS` (по умолчанию 5 минут), действие отклоняется.

## Автозапуск

```powershell
Remoter.exe --install-autostart     # добавить в HKCU\...\Run
Remoter.exe --uninstall-autostart   # убрать
```

То же самое есть в меню иконки в трее. Двойной клик по иконке открывает папку с логами.

## Сон и выключение ПК

Во сне Windows замораживает все программы и отключает сеть, поэтому бот **не может**
принимать сообщения и выполнять задачи, пока ПК спит. Это ограничение системы, а не бота.

Что происходит после пробуждения:

- бот сам переподключается к Telegram и к OpenCode (перезапускать не нужно);
- сообщения, отправленные во сне, Telegram хранит до 24 часов — они придут сразу после
  пробуждения и выполнятся;
- если задача была прервана сном, её можно повторить или отменить через `/cancel`.

Чтобы бот работал круглосуточно, не дай ПК засыпать:

```powershell
# в .env рядом с Remoter.exe
PREVENT_SLEEP=true
```

Или включи в меню трея пункт **«Не давать ПК засыпать»**. Экран при этом может гаснуть —
это нормально, программы продолжают работать.

Для ноутбука дополнительно проверь действие при закрытии крышки: «Сон» нужно заменить
на «Ничего не делать» (только для питания от сети).

Если ПК всё же уходит в сон, разбудить его удалённо можно через Wake-on-LAN, но для
этого нужен другой постоянно включённый компьютер или роутер — сам бот во сне не работает.

## Настройки

Основные значения — в `appsettings.json` рядом с exe. Их можно переопределить в `.env`:

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | — | Токен бота (обязателен) |
| `ALLOWED_USER_IDS` | — | Белый список Telegram ID (обязателен) |
| `DEFAULT_DIRECTORY` | `~` | Рабочая папка по умолчанию (`~` — домашняя папка) |
| `MODEL_PROVIDER` | `opencode` | Провайдер модели |
| `MODEL_ID` | `deepseek-v4.1-flash-free` | Модель |
| `AGENT` | `build` | Агент по умолчанию |
| `APPROVAL_TIMEOUT_SECONDS` | `300` | Таймаут подтверждения |
| `AUTO_START_OPENCODE` | `true` | Поднимать сервис OpenCode самому |
| `OPENCODE_COMMAND` | `opencode.cmd` | Как вызывать OpenCode |
| `PREVENT_SLEEP` | `false` | Не давать ПК засыпать, пока работает бот |

## Где лежат данные

- Настройки: `.env` рядом с `Remoter.exe` (или в корне проекта при `dotnet run`).
- Состояние чатов: `%LOCALAPPDATA%\Remoter\state.json`.
- Логи: `%LOCALAPPDATA%\Remoter\logs\remoter-ГГГГ-ММ-ДД.log` (хранятся 14 дней).
- Скриншоты и временные диффы: `%TEMP%`, удаляются сразу после отправки.

## Сборка

```powershell
dotnet build
dotnet test
dotnet publish src\Remoter.App -c Release -r win-x64 --self-contained false `
  -p:PublishSingleFile=true -o publish
```

Готовый `publish\Remoter.exe` (рядом лежит `appsettings.json`) — нужен установленный
.NET 10 Desktop Runtime. Для полностью автономной сборки замени `--self-contained false` на `true`.

## Если что-то не работает

- **«Не задан TELEGRAM_BOT_TOKEN»** — токен не попал в `.env` рядом с exe. Проверь путь
  в меню трея «Открыть .env».
- **Бот молчит** — проверь, что твой ID есть в `ALLOWED_USER_IDS`, и посмотри лог.
- **`Free usage limit reached` / `Insufficient balance`** — закончился лимит или баланс
  провайдера. Выбери другую модель через `/model` или пополни счёт OpenCode.
- **Сервис OpenCode не стартует** — выполни `opencode service status` вручную.
  В PowerShell используй `opencode.cmd` (скрипт `.ps1` может блокироваться политикой выполнения).
- **`/screen` возвращает ошибку** — экран заблокирован; это ожидаемо. Задачи при этом
  продолжают выполняться.
- **HTML не отправился** — бот автоматически повторяет сообщение обычным текстом.

## Безопасность

- Бот слушает только long polling, никаких входящих портов.
- Токен и белый список — только в `.env`, который исключён из git.
- Неизвестные пользователи игнорируются; при пустом белом списке бот лишь подсказывает ID.
- Опасные действия подтверждаются кнопкой; таймаут отклоняет запрос.
- В логах токен заменяется на `***`.
